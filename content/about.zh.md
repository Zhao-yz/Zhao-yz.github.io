## AI / Agent 实践

**个人 Agent 工作台**（Claude Code + Codex，2026.02 至今）

- 搭建多设备同步的个人 agent 工作台：50 个活跃 skill、多 agent 协作规范，覆盖会议纪要、多人协作云文档的起草与按评论改稿、流程图绘制、课程管理、信息采集等日常任务；仓库累计 2,600+ 次提交。
- 自进化回路：设计 sleep-review，每天扫描 Claude Code 与 Codex 的会话记录，识别用户纠正、重复任务和 skill 摩擦，产出三级改进提案（记忆 / skill 增补 / 结构改动），人审后落地。
- 搜索能力建设：把搜索当作 agent 的上下文供给持续建设，建立按查询类型的路由，付费接入 DeepSeek、Exa 等多家中英文搜索 API，沉淀成自己的搜索 skill。
- 多模型协作：model-council 让 5 个模型盲答、匿名互评，再由主席综合共识与分歧；cross-review 让 Claude 与 Codex 交替评审并实测工件。
- Agent 行为观察日志：持续记录 agent「做对了但没做好」的真实案例，按现象、归因、PM 视角拆解。
