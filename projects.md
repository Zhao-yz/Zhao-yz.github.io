Apps I built with Replit Agent for Introduction to Coding for MBAs at Berkeley Haas (Fall 2026).

## [Birthday Countdown](https://birthday-countdown-yuzhang95.replit.app)

A birthday countdown web page built with plain HTML, CSS, and JavaScript.

## [Silicon Valley History Quiz](https://silicon-valley-history-quiz.replit.app)

A quiz game on Silicon Valley history with scoring, a Show Code Concepts panel, and an object-oriented Question and Quiz class design.

## [Interactive Expense Tracker](https://interactive-expense-tracker-yuzhang95.replit.app)

An expense tracker with an in-browser SQLite database, a live SQL console, a schema view, and an animated diagram of how data moves from the interface to the database.
